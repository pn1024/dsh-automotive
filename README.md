# 汽车政策研究台（DSH 插件）

把「政策原文 + 月度销量 + 上市公司财报 + 行情」做成一个可下钻、可出报告、能对外的汽车产业研究工作台。

做成 DeepSeek Harness（DSH）插件：左侧栏一个入口，打开是深色控制台面板；
同时向模型暴露 6 个工具，可以直接问「九月有哪些智能网联政策」「奇瑞上个月出口多少」。

> 原则：**没有可核验来源的数据不展示、不估算、不进报告。** 所有政策都带官方原文链接，所有销量都能回到车型明细。

## 功能

- **政策库**：国务院政策文件库、湖南省政府文件搜索、省工信厅、省发改委、国家法律法规数据库，共 78 条国内政策，全部带官方原文链接与正文
- **条款级证据**：从官方正文按段落抽取条款，标注作用对象、方向、是否含量化指标，点击回到原文该段
- **政策强度 PSI**：`100 × (1 − e^(−Σ(工具权重 × 层级系数 × 新鲜度) / 18))`，按月计算，90 天半衰期，不做跨月累加
- **月度销量**：懂车帝公开销量榜（零售/上险口径），全国、新能源、12 个品牌、264 条车型明细
- **奇瑞专项**：官网公告口径的集团销量、出口、新能源、分品牌明细（21 个月）
- **上市公司**：行情（东方财富）+ 季度财报 + 业绩预告 + 机构评级 + 一致预期与目标价 + 季报 PDF（巨潮资讯）
- **政策-财报联动**：政策按季度聚合，与 A 股 5 家整车企业季度财务同向对照
- **报告**：Markdown 报告（带质检：章节完整性、引用覆盖率、模糊表述、篇幅）+ 公文格式 Word 研究报告（GB/T 9704 版式）
- **数据留痕**：每次写盘前自动快照到 `data/archive/`，可一键回滚

| 奇瑞官方 | 奇瑞控股官网新闻中心 | 21 个月 |

**明确拿不到的数据**（已实测，不估算、不编造）：
分省汽车销量（懂车帝城市参数无效、湖南省统计局空壳、国家统计局 403、海关验证码）、
省厅部分栏目（JS 壳或 404）、欧盟政策（EUR-Lex 需 SPARQL）。

## 安装

需要 DeepSeek Harness（DSH）。

```bash
# 本地目录方式（推荐）
cd ~/.dsh/profiles/<你的 profile>
# 在 package.json 的 dsh.profile.bundles 里加入本地插件路径，
# 或在插件管理器里安装 auto-policy-plugin 目录
```

插件结构：`cordis.patch.yml` 注册 `auto-policy`，`package.json` 声明 `dsh.bundle.patch` 与 `dsh.client`。

## 使用

### 面板

左侧栏点击「汽车政策」打开控制台。可以：

- 选月份、选品牌，所有 KPI 跟着变
- 点任一数字下钻到构成它的记录（政策、车型、品牌、公式）
- 「国内政策全库」按年份筛选、按标题/机构/工具搜索、滚动浏览
- 条款文字点击展开全文，右列「原文 ↗」直达官方页面
- 「生成报告」按当前选择出报告，结果缓存本地不重复消耗；需要最新版点「重新生成」

### 模型工具

| 工具 | 作用 |
|---|---|
| `policy_search` | 按关键词/地区/层级/工具/日期检索政策 |
| `policy_read` | 读某条政策全文、条款、版本、官方链接 |
| `policy_analyze` | 按宏观-中观-微观分层分析，返回结论 + 证据 id + PSI |
| `policy_report` | 生成月度 Markdown 报告并落盘 + 质检 |
| `policy_library_stats` | 政策库概览（条数、层级、工具、地区、销量月份） |
| `auto_stock_quotes` | 国产汽车整车与生态公司行情 |

### 数据抓取脚本

```bash
cd auto-policy-plugin

# 政策
node scripts/ingest.mjs --pages=2 --content          # 国务院政策文件库
node scripts/ingest-hunan.mjs --pages=3              # 湖南省政府门户
node scripts/ingest-gxt.mjs --pages=7                # 省工信厅（PowerShell 通道）
node scripts/ingest-fgw.mjs --pages=25               # 省发改委（PowerShell 通道）
node scripts/ingest-flk.mjs                          # 国家法律法规数据库

# 市场数据
node scripts/sales-dongchedi.mjs --months=10         # 懂车帝销量
node scripts/ingest-chery.mjs                        # 奇瑞官方公告
node scripts/ingest-financials.mjs                   # 财报 + 预告 + 评级 + 一致预期 + PDF

# 运维
node scripts/sources.mjs check                       # 数据源健康检查
node scripts/backup.mjs snapshot                     # 数据快照
node scripts/smoke.mjs 2026-09 100000 奇瑞            # 回归测试
node scripts/build-research-docx.mjs                 # 生成 Word 研究报告
```

### 报告

- Markdown：`policy_report` 工具或面板「生成报告」，落盘到 `reports/`
- Word：`node scripts/build-research-docx.mjs`，输出到 `data/reports/`，公文格式（A4，页边距 37/35/28/26mm，标题二号小标宋、正文三号仿宋、一级标题三号黑体、二级标题三号楷体）

## 已知限制

- 政策正文抽取不是版式无关的爬虫，附件型政策只能看到通知正文
- 懂车帝是零售/上险口径，不能与厂商批发量、奇瑞集团公告数相加或直接比较
- 品牌「政策相关度」是关键词匹配，不是弹性估计；报告里标为非因果
- PSI 权重是研究先验，适合看同口径相对变化，不适合当绝对政策力度
- 分省销量、奇瑞出口分月明细（部分月份）、欧盟政策仍未接入
- 省工信厅、省发改委只认 Windows `Invoke-WebRequest`（Node 与 curl 均被拒），且频繁超时需重试

## 数据口径

| 数据 | 口径 | 不能和谁相加 |
|---|---|---|
| 懂车帝销量 | 零售/上险（终端） | 厂商批发量、奇瑞集团公告数 |
| 奇瑞集团公告 | 集团批发，含出口 | 国内上险量 |
| 奇瑞港股上市公司 | 奇瑞汽车股份（9973.HK） | 集团口径 |
| 财报 | A 股营业总收入/归母净利；港股营业额/股东应占溢利；各自本币 | 不做汇率折算 |
| PSI | 研究先验权重 | 不是绝对政策力度 |
