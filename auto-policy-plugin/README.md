# 汽车政策研究台（dsh-plugin-auto-policy）

左侧栏底部「汽车政策」入口 + 一个可下钻的政策与产业控制台。
它把政策原文、全国/品牌销量、车型明细和上市公司行情放在同一个面板里，
并且坚持一条底线：**没有真实来源的数据，不展示、不计算、不写进报告。**

## 月份与空月处理

国务院文件库通常比销量滞后 1—2 个月，所以面板**默认停在“最近一期有政策的月份”**，而不是最新销量月；
否则打开就是 0 条政策。

- 月份下拉里 `●` 表示该月有官方政策，`○` 表示只有销量；
- 如果手动切到没有政策的月份，顶部会出现提示条：「本月无新政策，最近一期是 YYYY-MM」，一键跳回；
- `policy_report` 不传月份时，同样落在最近一期有政策的月份。

## 面板能做什么

- **品牌可选**：奇瑞、比亚迪、吉利、长安、上汽、长城、特斯拉、理想、小鹏、蔚来、零跑、小米。
  品牌零售、份额、12 个月序列和当月政策相关度随选择重算。
- **全国 / 湖南**：区域视图只统计该区域有官方原文的政策，包含区域 PSI、层级、发文机构和市州分布；
  没有区域销量时不显示湖南销量或渗透率。
- **指标下钻**：
  - 政策工具 → 该工具下的真实政策清单，逐条进入详情或打开官方原文；
  - 品牌份额 / CR5 → 品牌表，再进入车型级明细（车型、原始品牌名、销量、品牌内占比）；
  - NEV 渗透率 → 各月乘用车、新能源、渗透率与计算公式；
  - PSI → 公式、权重口径与构成政策；
  - 区域画像 → 本区域政策清单与官方链接；
  - 上市公司 → 东方财富个股页。
- **条款证据**：从官方正文按段落抽取，显示原文位置、条款摘录与直接作用对象；
  点击政策名进入详情，点击「原文 ↗」打开官方页面。没有正文就不生成条款。
- **报告**：头部「报告」按钮直接生成 Markdown 月报，显示字数、引用覆盖率和质检结果，
  支持复制与下载。要写入工作区 `reports/`，调用 `policy_report` 工具。
- **点击穿透**：卡片以外的页面仍可正常点击和输入；标题栏可拖动，双击复位，Esc 关闭。
- **自动刷新**：面板「自动」开关每 5 分钟重新请求；行情服务端缓存 10 分钟，另有 8 分钟预热。

## 报告结构（v2）

1. 执行摘要：政策、市场、竞争三侧事实，明确不做未识别的因果归因；
2. 关键指标：每个指标带口径与证据 ID；
3. 宏观：全国政策证据表与工具结构；
4. 中观：区域政策与市场结构，有真实区域数据才展示；
5. 微观：品牌份额、条款原文定位与官方链接；
6. 品牌专项：当月零售、份额、环比/同比（有数据才显示）与政策证据；
7. 资本市场映射：行情与政策、销量分开呈现；
8. 研究边界与跟踪清单：缺数据、口径差异、不能做的推断；
9. 附录：政策证据索引、公式、数据源和免责声明。

质检会检查章节完整性、引用覆盖率（≥90%）、模糊表述、示例口径、重复证据前缀和篇幅。
本期没有政策与销量证据时，报告会标记为不可发布，不编造月度结论。

## 真实数据源

| 内容 | 来源 | 口径 |
|---|---|---|
| 国内政策 | 国务院政策文件库 `sousuo.www.gov.cn/search-gov/data` | 标题、文号、机构、日期、官方链接；正文按政府网站容器抽取 |
| 国际政策 | 美国联邦公报 `federalregister.gov/api/v1` | 官方 API，含 `html_url` 与 `raw_text_url`；只收标题/摘要涉及汽车的条目 |
| 全国乘用车销量 | 懂车帝公开销量榜 `rank_data_type=11` | 车型月度销量汇总，上险/终端口径，不是厂商批发 |
| 全国新能源销量 | 同一榜单 `new_energy_type=1/2/3` 相加 | 纯电 + 插混 + 增程 |
| 品牌销量 | 榜单 `brand_name` 聚合子品牌 | 车型明细与品牌汇总同一次抓取 |
| 上市公司行情 | 东方财富 `push2` / `push2his` | 现价、涨跌、市值、PE、近 20 日收盘，缓存 10 分钟 |
| **奇瑞官方公告** | 奇瑞控股官网 `/api/article/paginate` | 集团月度销量、出口量、**新能源销量**、港股上市公司（9973.HK）销量、**分品牌销量**（奇瑞/星途/捷途/iCAR/智界）；需 appId+md5 签名，已复现 |
| **地方性法规** | 国家法律法规数据库 `flk.npc.gov.cn/law-search/search/list` | 湖南省级车辆相关法规（道路运输、道路交通安全、超限超载）：标题、制定机关、公布/施行日期、法律性质、官方详情链接。**只给元数据**，正文在内部 OSS 拿不到 |
| **省工信厅规范性文件** | `gxt.hunan.gov.cn/gxt/xxgk_71033/zcfg/gfxwj/` | 7 页 136 条规范性文件，含文号与发布日期；车辆相关 2 条。**只有 Windows Invoke-WebRequest 能取**，Node 与 curl 均被拒 |
| **省发改委通知公告** | `fgw.hunan.gov.cn/fgw/xxgk_70899/tzgg/` | 25 页 500 条通知公告；充电/新能源汽车相关 2 条（成品油价格通知属重复公告，未入库）。同样只认 PowerShell，频繁中断需重试 |

**明确没有的数据**：有效分省销量、湖南 NEV 渗透率、经回归标定的政策弹性与政策对销量的因果贡献。
这些位置不会用示例数字补齐。奇瑞出口现在有官方来源（公告口径，含出口），与懂车帝国内上险口径**并列展示、不相加**。

## 数据源注册表与健康检查

`data/sources.json` 登记了每个源的层级、地区、限速、robots 判定、许可证与实测状态。
新增源只改这份配置，不改代码；`enabled: false` 的源不会参与抓取。

```powershell
node scripts/sources.mjs check      # 逐个探测，写回状态与 data/source-health.json
node scripts/ingest-intl.mjs        # 抓国际政策（联邦公报）
```

实测结果（2026-11-23）：

| 源 | 状态 | 说明 |
|---|---|---|
| 国务院政策文件库 | ✅ 可用 | totalCount 正常 |
| 美国联邦公报 | ✅ 可用 | 5 组查询命中 55 份汽车相关文件 |
| **湖南省政府站内「文件搜索」** | ✅ 可用 | 关键词 + 分页，返回标题/文件类型/文号/日期/原文链接；已入库 6 条省级政策 |
| 湖南省工信厅 / 省发改委子站 | ❌ 不可用 | 栏目路径 JS 跳转后超时或 404 |
| 长沙市政府 | ❌ 不可用 | 返回 54 字节空壳 |
| 株洲市政府 | ⚠️ 部分 | 首页可访问，栏目前端渲染，无可解析列表 |
| 欧盟 EUR-Lex | ❌ 不可用 | 检索接口 202 空响应，需 SPARQL/Cellar |

### 湖南源的三个坑（已解决，供以后复用）

1. **`www.hunan.gov.cn` 需要 TLS 曲线**：ECDHE 点位会让 OpenSSL 报 `bad ecpoint`，必须
   `ecdhCurve: 'prime256v1'`；目录页是 JS 壳，真实数据在 `wjk_json.html` 的 JSONP（单引号字面量）。
2. **`searching.hunan.gov.cn` 不认 Node**：Node 请求一律超时，只能走 `curl.exe`；
   但它是**服务端渲染**的，`/hunan/102000000/file?q=汽车&page=N` 直接给结果块
   （`.resultbox` 内含标题、文件类型、发文字号、发布日期、原文链接）。
3. **站内搜索按全文匹配**：会把天然气、储能、电价、营商环境等文件带出来，必须再过一层
   **标题汽车相关性过滤**；湖南站转载的国家文件要按部委前缀/文号改判为国家级，否则湖南视图虚高。

当前库：**78 条国内政策**（国家 65 · 湖南 13），其中 74 条有全文，3 条只有元数据与官方链接（地方性法规），1 条只有摘要。
湖南 13 条的来源分布：省政府门户 7 · 省工信厅 2 · 省发改委 2 · 国家法律法规数据库 3（其中 1 条与国家条目同源）。
国际政策（57 条）按要求保留在数据文件里，但**面板、分析、报告一律不再纳入**（加载时排除，`library.meta.excludedInternational` 记录条数）。
**2023-01 至 2026-09 每个月都有国内政策**；面板提供「国内政策全库」卡片，可按年份筛选、按标题/机构/工具搜索、滚动浏览全部条目。

### 面板的三个已知问题（本轮已修）

1. **新能源渗透率/政策走势显示为空**：不是没数据，而是面板停在旧月份（2026-10 无政策）。现在默认月份改为
   “最近一期有政策的月份”，图表无数据时也会显示原因而不是空白。
2. **政策列表只有几条、不能滚动**：政策清单与条款清单都改成固定高度可滚动，且不再截断（政策全量、条款 12 条）。
   另加层级筛选（全部 / 国家 / 国际 / 省级 / 市级，带条数、空层级置灰），条款文字默认两行、点击展开全文。
3. **国际政策抽不到条款**：条款引擎原来只认中文，已补英文规则（electric vehicle / fuel economy /
   emission standard / charging infrastructure 等），SAFE 规则现在能定位到 5 条条款。
4. **报告页报错**：报告入口改成显式「生成报告」按钮，按当前选中的月份与品牌生成；子路由按候选路径回退
   （热重载后旧路径不会 404），失败时显示具体 HTTP 状态与原因，并给「重试」。
   **报告生成后会缓存**（内存 + localStorage），再次点开直接复用，不重复请求、不重复消耗；需要最新版时点「重新生成」。
5. **趋势图太单一**：一度改成“销量+渗透率+政策条数”三合一联动图，实际显示效果不好（跨列留白、拥挤），
   已回退为独立的「政策强度走势」与「新能源渗透率」两张卡，各占一列，版面不留空。
6. **湖南/全国分不开**：公开渠道没有有效分省销量，湖南视图的数字其实是全国的，已移除地区切换，
   统一标「全国口径」，避免把全国数当湖南数看。

面板页脚显示 `SRC 2/8`，悬停可见每个源的判定；报告第八章有「数据质量快照」列出源状态。

## 存量数据保护（快照与回滚）

政策库、销量、源配置都会**在每次写盘前自动快照**，避免抓取出错时把已有数据覆盖掉。

```powershell
node scripts/backup.mjs snapshot          # 立即打一份快照
node scripts/backup.mjs list              # 查看已有快照
node scripts/backup.mjs restore <文件名>   # 回滚（回滚前会再给当前状态打一份）
```

- 快照位置：`data/archive/<时间戳>-<来源>/`，含 `policies.json`、`sales.json`、`sources.json`、`source-health.json`；
- 同时在 `data/archive/` 顶层留一份 `policies__<时间戳>__<来源>.json`，只靠文件名也能找回；
- 默认每个来源保留最近 40 份，超出自动清理；
- `ingest.mjs`、`ingest-intl.mjs`、`ingest-hunan.mjs`、`sales-dongchedi.mjs` 已在写盘前调用 `backupBeforeWrite()`；
- 另有 `data/policies.seed.json` 保存最初接入时的种子数据，不会被覆盖。

## 数据入库与月更

```powershell
# 政策：抓取 + 合并 + 正文
node scripts/ingest.mjs --pages=2 --content
node scripts/ingest.mjs --refresh-content --limit=40
node scripts/ingest.mjs --prune

# 按时间范围补齐某年/某月（时间参数走接口的 timezd 模式）
node scripts/ingest.mjs --since=2026-01-01 --until=2026-12-31 --keywords=汽车,新能源汽车,充电,换电

# 国际政策：美国联邦公报（也支持 --since/--until 补月份）
node scripts/ingest-intl.mjs --content-limit=20
node scripts/ingest-intl.mjs --since=2026-03-01 --until=2026-03-31

# 奇瑞官方月度销量/出口（集团口径，来源可点）
node scripts/ingest-chery.mjs

# 数据源体检
node scripts/sources.mjs check

# 湖南省级政策（站内文件搜索，curl 通道）
node scripts/ingest-hunan.mjs --pages=3 --keywords=汽车,新能源汽车,充电,换电,智能网联

# 销量：全国 + NEV + 品牌 + 车型明细
node scripts/sales-dongchedi.mjs --months=10

# 有授权的乘联会/省级数据时，走 CSV 导入
node scripts/ingest.mjs --sales-file=D:\data\cpca.csv
# CSV 表头：month,scope,total,nev,yoyTotal,yoyNev,chery_retail,chery_export
# scope = national | hunan
```

数据文件有 mtime + size 指纹，写入后下一次请求即生效，无需重启。
DSH 定时任务「汽车政策库月度更新与月度报告」每月 3 日 09:00 执行以上抓取与报告流程。

## Word 版研究报告

面板与工作区都提供公文格式（GB/T 9704 版式）的研究报告：

\powershell
node scripts/build-research-docx.mjs              # 用最近有政策的月份
node scripts/build-research-docx.mjs --month=2026-09
\\n
- 正文由模型按真实数据撰写（研究判断与事实分开表述），不是数据罗列；
- 版式：A4，页边距上 37 / 下 35 / 左 28 / 右 26 mm，标题二号小标宋、正文三号仿宋、一级标题三号黑体、二级标题三号楷体；
- 含两张表：近三个月零售与渗透率、奇瑞集团分品牌销量；
- 输出到 data/reports/policy-research-YYYY-MM.docx，面板通过 /report.docx?month= 下载。

## 插件代码更新后如何生效

改了 lib/ 或 index.js 后，宿主进程仍在跑旧模块，**必须重新加载插件**才会生效：

1. 首选：在插件管理器里把 include:auto-policy 先禁用再启用（不触发 pnpm，不会被 MCP 进程的文件锁挡住）；
2. 备选：安装临时 reload bundle（需要 pnpm 能重写 profile 的 node_modules，若报 EPERM 说明被占用）；
3. 前端改动（client.js）只需浏览器刷新；若没变化用 Ctrl+Shift+R 强刷。

改了 data/ 下的数据文件不需要重载，面板每次请求都会重新读盘。

## 已知缺点与边界

- 政策正文抽取不是版式无关的爬虫：部分附件型政策只有通知正文，需点官方原文看附件。
- 公开销量榜与乘联会口径不同，不能把全国上险量与厂商批发量直接比较。
- 奇瑞出口已有官方来源（集团公告口径），但只解析出 21 个月、其中 10 个月带出口；2026 年各月公告尚未发到可解析格式。
- 品牌“文本相关度”只是关键词匹配，不是政策弹性；报告明确标为非因果。
- PSI 的权重是研究先验，适合看同口径相对变化，不适合解释为绝对政策力度。
- 国际政策目前只有美国联邦公报，欧盟 EUR-Lex 需要 SPARQL/Cellar 或官方 key，尚未接入。
- 湖南省级政策：省门户文件搜索已翻 10 页 × 8 组关键词，确认**饱和在 7 条**；省厅子站（gxt/fgw/czt）栏目路径未打通，且 gxt 对 Node/curl 不应答、PowerShell 也时常超时。
- 分省销量：懂车帝 `city_name` 参数无效；湖南省统计局页面被拦（返回 66—75 字节空壳）；国家统计局返回 403；海关总署需验证码。三条路都不通。
- 大库下的检索仍是内存关键词评分，未来需要倒排索引或向量检索。
- 当前报告是规则引擎生成的证据报告，不是自由发挥的长文；这样可复核，但文风较克制。

关闭插件后不再注册工具、不再注册面板，也不再发起行情请求；已有报告和数据文件保留。
